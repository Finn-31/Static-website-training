
# Internship Assignment – Static Website Development Training

## Project Overview
A static, responsive website developed using a provided Figma design reference.

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Roboto)

## Features
- Responsive navigation menu
- Hero section with illustrations
- Compliance information section
- Feature cards
- CSS hover effects
- Smooth scrolling
- Responsive layouts for desktop, laptop, tablet and mobile

## Responsive Testing
- Desktop: 1400px
- Laptop: 1280px
- Tablet: 768px
- Mobile: 375px

## Project Structure
- index.html – Website structure
- style.css – Styling and responsive layouts
- assets/images – Website illustrations

## Live Website
https://abdussameevasaikar.github.io/Internship_Assignment/

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser.

## Project Type
Static responsive website using HTML and CSS.
